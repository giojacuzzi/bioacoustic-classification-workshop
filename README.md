# bioacoustic-classification-workshop

Materials for a hands-on workshop demonstrating the bioacoustic classification for species detections from passive acoustic monitoring data. Created by [Giordano Jacuzzi](https://www.giojacuzzi.com/), PhD (Chorus Bioacoustics Research LLC).

> This repository contains open source software originally developed by Jacuzzi, G., Olden, J.D., 2025. "Few-shot transfer learning enables robust acoustic monitoring of wildlife communities at the landscape scale". _Ecological Informatics_ 90, 103294 [![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.15694435.svg)](https://doi.org/10.5281/zenodo.15694435). Please cite the original publication in your references if you repurpose these materials for your own work.
> Example audio data are provided by the Washington State Department of Natural Resources, recorded at the Olympic Experimental State Forest for OESF Research and Monitoring ([Minkova et al., 2020](https://dnr.wa.gov/sites/default/files/2025-03/lm_oesf_pac_sp.pdf)).

### Prerequisites

- Windows 11+, macOS 14+ (Intel Macs not supported)
- [Raven Annotate](https://www.ravensoundsoftware.com/software/raven-workbench/raven-annotate/) or [Raven Lite](https://www.ravensoundsoftware.com/software/raven-lite/) software
- [BirdNET-Analyzer GUI](https://birdnet.cornell.edu/analyzer/) software
- [RStudio Desktop](https://docs.posit.co/ide/user/download.html) programming environment
- Workshop materials
